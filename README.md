# CR Reserve

Telegram Mini App для поставок и резервов «Цифрового Рая».

Бот: https://t.me/CR_Reserve_Bot/CR_Reserve

## Реализовано

- Список поставок: сортировка по публикации или ожидаемому поступлению, статусы и поиск.
- Товары с фотографиями, артикулами, ценой и свободным количеством.
- Резерв сразу уменьшает общий свободный остаток. Повтор сетевого запроса не создаёт второй резерв.
- Отмена возвращает остаток один раз. Подтверждение менеджером не списывает товар повторно.
- Мои резервы и управление резервами владельцем, выгрузка в XLSX.
- Управление поставками внутри приложения: загрузка Excel, предпросмотр, сжатие изображений, дата и описание, публикация/закрытие.
- Оповещения о резервах в Telegram-канал с очередью повторных попыток при недоступности Telegram.
- Telegram initData проверяется на сервере. Доступ владельца — по числовому Telegram ID, а не username.
- Прайсы загружаются владельцем в защищённом разделе; реальные цены, остатки и фотографии не публикуются в GitHub. В предпросмотре только условные демо-данные.

## Статус запуска

Код готов к подключению, но сам репозиторий не является работающим сервером.
Без BOT_TOKEN открывается честный предпросмотр без отправки резервов. С настроенным ботом данные видны только после входа через Telegram.
Без RESERVATION_CHAT_ID реальные резервы заблокированы.

## Хостинг

Код хранится в GitHub. Рабочее приложение рассчитано на Cloudflare Workers + SQLite Durable Object + Workers Static Assets (один адрес).
GitHub Pages не запускает серверную часть и ограничивает коммерческое использование: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

Инструкция запуска: [docs/SETUP.md](docs/SETUP.md).

## Локальная проверка

Требуется Node.js 24:

```sh
npm test
npm run preview
```

Предпросмотр: http://localhost:4173. Это условные демо-товары, не настоящие резервы.

Для локального Cloudflare-сервера: скопируйте `.dev.vars.example` в `.dev.vars`, заполните настройки и запустите `npm run dev`. Секреты не коммитить.

## Правила данных

- Цена хранится в целых копейках; расчёт выполняется сервером.
- Кол-во в импортируемом Excel означает весь объём поставки до резервов. При обновлении из него вычитаются уже действующие резервы.
- Товар с резервами нельзя удалить или уменьшить его общее количество ниже резерва.
- Существующие резервы сохраняют цену и название на момент оформления.
- Даты в исходных примерах отсутствуют; вымышленные даты не добавлены.
- Каждый резерв относится к одной поставке. Не более 100 разных товаров в одном резерве.
- Лента резервов возвращает последние 1000 записей. До роста выше этого объёма требуется пагинация/архивный экспорт.

## Ограничения первой версии

- Приём Excel реализован в разделе «Управление» приложения. Отправка файла боту даёт инструкцию, но не импортирует файл автоматически.
- Автоматической массовой рассылки новых поставок клиентам нет. Можно отправить ссылку на приложение обычным способом.
- Изменения статуса резерва видны в приложении; уведомления отправляются в рабочий канал. Личные уведомления клиентам не включены.
- При редком сбое между успешной отправкой Telegram и записью результата уведомление может дублироваться. Номер резерва одинаковый; сам резерв и остаток не дублируются.
- Отсутствуют онлайн-оплата, интеграция с 1С и отгрузка. Приход, продажи вне приложения и изменения общего количества обновляет владелец.

## Зависимости

Клиент: обычный HTML/CSS/JS, JSZip (MIT, лицензия в public/JSZIP-LICENSE.md). Сервер использует Web Crypto и Cloudflare Storage. Wrangler 4 вызывается при разработке/деплое. Никакие зависимости клиент не загружает с npm/CDN; исключение — официальный Telegram SDK.
Повседневная загрузка Excel выполняется через приложение. Реальные данные сохраняются в базе Cloudflare и не попадают в репозиторий.
